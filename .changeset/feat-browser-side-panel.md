The agent's own Chrome window shows what it does in Chrome's side panel, next to the page: the state, a "Now" card with the step it runs and how long it has run, its steps with an icon and a color per kind, "Thought for N s" between calls and a line per site, Pause and Hand back, an amber card with "I am done" when the agent waits for you, and a button that opens the live view. It is on by default for a Chrome with a window that turno starts, with the live view on (not headless, not in attach mode, not with Lightpanda or Camoufox); `turno-browser set <id> --side-panel false` (identity.json `"sidePanel": false`, format 14) turns it off. The panel is a small extension shipped in the package and loaded at each start over the DevTools protocol (`--enable-unsafe-extension-debugging`), with the `sidePanel` permission only: no content scripts, no host permissions, no web accessible resources. It reads the live view's server on 127.0.0.1 with a code handed over the protocol to its service worker and a token of its own, never through a page. A page sees the narrower window the panel leaves (`innerWidth`, and a `resize` when it opens), as with a person's side panel; the reputation bench's probe shows no element and no main world call, and its new `extension-resources` check that no page can load a file of the extension. See [the side panel](https://turno.wimo.dev/docs/browser/live-view#the-side-panel-in-the-agents-window).
