This page lists every environment variable turno reads. `turno help environment` prints the same list.

## Where turno keeps things

| Variable | What it does |
| --- | --- |
| `TURNO_CONFIG_DIR` | config.toml and mcp.toml (default: $XDG_CONFIG_HOME/turno, else ~/.config/turno) |
| `TURNO_STATE_DIR` | state, logs, caches and backups (default: $XDG_STATE_HOME/turno, else ~/.local/state/turno) |
| `TURNO_DATA_DIR` | installed servers and browser identities (default: $XDG_DATA_HOME/turno, else ~/.local/share/turno) |
| `TURNO_BIN` | where the launchers go (default: ~/.local/bin) |
| `TURNO_HUB` | Claude Code's shared folder (default: ~/.claude) |
| `TURNO_HUB_CONFIG` | Claude Code's shared .claude.json (default: ~/.claude.json) |
| `TURNO_FONT_DIR` | where turno ui installs the status line font |
| `TURNO_APPS_DIR` | where turno looks for terminal apps on macOS (default: /Applications) |
| `TURNO_CHROME_APP` | Google Chrome on macOS, for turno open (default: /Applications/Google Chrome.app) |
| `TURNO_CHROME_BIN` | the Chrome program on Linux, for turno open |

## How turno behaves

| Variable | What it does |
| --- | --- |
| `TURNO_NO_INPUT` | 1: never ask, exit 2 and name the flag instead (same as --no-input); 0: ask even inside an agent session |
| `TURNO_COLOR` | always, never or auto (same as --color); see the order below |
| `TURNO_ALLOW_PLAIN` | 1: turno auto runs the plain agent when config.toml does not parse |
| `TURNO_SAFE` | 1: turno run, turno &lt;profile&gt; and turno auto open the agent in safe mode, without the gateway and the status line (same as --no-gateway) |
| `TURNO_NO_UPDATE_CHECK` | 1: no daily update check and no notice |
| `TURNO_NO_UPDATE_NOTIFIER` | 1: same as TURNO_NO_UPDATE_CHECK (the name gh uses) |
| `TURNO_REGISTRY` | npm registry for update checks (default: npm_config_registry, else registry.npmjs.org) |
| `TURNO_BROWSER_IDLE` | turno-browser closes Chrome after this long without a tool call (default: 15m) |
| `TURNO_BROWSER_SNAPSHOT` | full: turno-browser returns page snapshots as Playwright writes them; compact: no changes on an action's result (default: compact, a table of contents for a long page, and an action that stays on the page answers with what changed) |
| `TURNO_BROWSER_BACKGROUND_IDLE` | the background server of a browser identity exits after this long without a request (default: 15m; 0: never) |
| `TURNO_BROWSER_EXIT_CHECK` | 0: turno-browser does not look up where a proxy exits (one HTTPS request to get.geojs.io through the proxy, once a day) |
| `TURNO_LIGHTPANDA_PATH` | the Lightpanda binary turno-browser's read mode runs (default: lightpanda on PATH) |
| `TURNO_BROWSER_SESSION` | the session name of turno browser do (same as --session; default: default), to keep several apart |
| `TURNO_CAMOUFOX_PATH` | the Camoufox executable turno-browser's camoufox engine runs (default: the newest in Camoufox's cache) |
| `TURNO_PLAYWRIGHT_CORE` | the playwright-core folder the camoufox engine runs on (default: the one next to turno-browser) |
| `TURNO_BROWSER_ACT_CLI` | off: natural language actions never run the Claude Code CLI or Codex (MCP sampling and API keys still count) |
| `TURNO_BROWSER_CAPTCHA_ENDPOINT` | a task-api captcha solver's URL, for identities without a captcha group (with TURNO_BROWSER_CAPTCHA_KEY) |
| `TURNO_BROWSER_CAPTCHA_KEY` | that solver's account key, hidden from every result |
| `TURNO_BROWSER_NOTIFY` | off: turno-browser shows no notification of the system, for any identity |

## Set by turno for the agents it starts (read them, do not set them)

| Variable | What it does |
| --- | --- |
| `TURNO_PROFILE` | the profile a launcher opened |
| `TURNO_AGENT` | that profile's agent (codex, copilot, cursor) |
| `TURNO_SESSION_PID` | the agent's process id, sent to the gateway |
| `TURNO_SESSION_CWD_B64` | the agent's folder (base64url), sent to the gateway |
| `TURNO_MCPD_TOKEN` | the profile's gateway token, for agents that read headers from the environment |
| `TURNO_MCPD_SERVICE` | set by the mcpd service file (LaunchAgent or systemd unit) |
| `TURNO_BROWSER_PROMPTED_PARAMS` | set by turno browser replay for the server it starts: the parameters typed at its hidden prompt |
| `TURNO_BROWSER_ACT_CHILD` | set by turno-browser for the Claude Code CLI or Codex it runs: a turno-browser under it never runs one again |

## Standard variables turno honors

| Variable | What it does |
| --- | --- |
| `NO_COLOR` | set and not empty: no colors (no-color.org) |
| `FORCE_COLOR` | 0 or false: no colors; anything else: colors, also in a pipe |
| `CLICOLOR_FORCE` | set and not 0: colors, also in a pipe |
| `CLICOLOR` | 0: no colors |
| `TERM` | dumb: no colors |
| `COLUMNS` | the width to lay out for (default: the terminal's, else 80) |
| `DO_NOT_TRACK` | 1: no update check (turno sends nothing else anywhere) |
| `CI` | set: no update check |
| `NO_UPDATE_NOTIFIER` | 1: no update check |
| `XDG_CONFIG_HOME`, `XDG_STATE_HOME`, `XDG_DATA_HOME`, `XDG_CACHE_HOME` | base folders, when the TURNO_* ones are not set |
| `VISUAL`, `EDITOR` | the editor of turno config edit |
| `NODE_COMPILE_CACHE`, `NODE_DISABLE_COMPILE_CACHE` | Node's compile cache (turno keeps it in $XDG_CACHE_HOME/turno) |
