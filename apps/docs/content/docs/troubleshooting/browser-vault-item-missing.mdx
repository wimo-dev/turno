This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  vault: <label> has no item for the credentials of <site>, so browser_login cannot sign in there
     fix: turno browser vault add <id> <site> --url <sign-in page> --username <name>
```

It is a failure; a failure makes `turno browser doctor` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

The vault index lists the site, and the secret store has no item for it: it was deleted by hand, or the index was copied from another machine. browser_login then has nothing to fill in. doctor only asks whether the item exists.

## Fix

Run:

```sh
turno browser vault add <id> <site> --url <sign-in page> --username <name>
```

`turno browser doctor --fix` does not run it for you, because it needs a decision or an answer from you.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
