This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  <label> still has the MCP server <server> (<file>), and there is no identity "<id>"
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

The agent's config runs turno-browser-mcp for an identity that no longer exists (it was removed before remove took agents' entries out, or by hand), so the agent shows a server that fails to start.

## Fix


Remove the entry with the agent's own command, which doctor prints (claude mcp remove --scope user browser-&lt;id&gt;, codex mcp remove browser-&lt;id&gt;, copilot mcp remove browser-&lt;id&gt;, gemini mcp remove -s user browser-&lt;id&gt;); for Cursor, delete the entry from ~/.cursor/mcp.json.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
