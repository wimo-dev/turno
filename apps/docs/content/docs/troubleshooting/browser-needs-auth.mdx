This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  NEEDS_AUTH: not signed in at <url>: <health> (checked <checked at>)
     fix: turno browser login <id>
```

It is a warning or a failure; a failure makes `turno browser doctor` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

The identity has a session health check: a page and what it shows only when signed in. The proof was missing the last time Chrome started, so tool calls fail until you sign in again by hand.

## Fix

Run:

```sh
turno browser login <id>
```

`turno browser doctor --fix` does not run it for you, because it needs a decision or an answer from you.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
