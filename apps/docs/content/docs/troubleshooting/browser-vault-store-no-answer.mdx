This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  the <label> did not answer for the vault: <first line>
     manual: unlock the keychain (or the Secret Service) and run doctor again
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

doctor asks the secret store whether each vault credential is there (a lookup; it never reads the value), and the store returned an error instead: most often the keychain is locked, or the Secret Service is not running in this session.

## Fix

Unlock the keychain (or the Secret Service) and run doctor again.

No single command fixes this one, so doctor names the manual step.

Unlock the keychain (or start the Secret Service, for example by signing in to the desktop) and run doctor again.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
