This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  Google Chrome not found, and no other Chromium-based browser (Edge, Brave, Chromium, Chrome for Testing)
     fix: turno browser install-browser
```

It is a failure; a failure makes `turno browser doctor` exit with code 1.

## Why it happens

turno-browser drives a Chromium-based browser you have installed: Google Chrome, Microsoft Edge, Brave or Chromium. None was found. `install-browser` downloads Chrome for Testing into your user cache, which needs no admin password.

## Fix

Run:

```sh
turno browser install-browser
```

`turno browser doctor --fix` does not run it for you, because it needs a decision or an answer from you.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
