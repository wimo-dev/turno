This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  memory pressure is <level> on this machine (<total> in all): every Chrome an identity opens adds to it
     manual: close the apps and browser sessions you do not need; where memory runs short often, turn on the low-resource preset for each identity: turno browser set <id> --resources low
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

The system reports memory pressure (the kernel's level on macOS, pressure stall information on Linux), the same reading mcpd uses to stop idle servers sooner. Each identity's Chrome holds a few hundred megabytes, more with many tabs open, so on a machine with little memory several sessions can push it into swapping or a restart. turno never closes a session that is working because of it.

## Fix

Close the apps and browser sessions you do not need; where memory runs short often, turn on the low-resource preset for each identity: turno browser set &lt;id&gt; --resources low.

No single command fixes this one, so doctor names the manual step.

Close the apps and browser sessions you do not need. Where memory runs short often, turn on the low-resource preset for each identity (turno browser set &lt;id&gt; --resources low): at most 2 tabs, idle tabs parked after 2 minutes, Chrome closed after 5 minutes without a call, and a note in tool results while memory is low.

Then run `turno browser doctor` again to see the row turn into `ok`.
