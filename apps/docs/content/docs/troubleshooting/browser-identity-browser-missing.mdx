This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  browser: <browser label> (<from>) is not installed, so this identity's browser does not start
     manual: install <browser label>, or pick another browser: turno browser set <id> --browser <name>
```

It is a failure; a failure makes `turno browser doctor` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

The identity opens its profile with the browser its identity.json names (`browser`), or Google Chrome when it names none, and that browser is not on this machine. turno never opens the profile in another browser on its own, since that can lose its sign-ins.

## Fix

Install &lt;browser label&gt;, or pick another browser: turno browser set &lt;id&gt; --browser &lt;name&gt;.

No single command fixes this one, so doctor names the manual step.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
