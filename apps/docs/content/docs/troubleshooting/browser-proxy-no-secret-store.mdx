This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  the proxy credentials are in the secret store, and this machine has none
     manual: install libsecret (secret-tool), or use a proxy without a password
```

It is a failure; a failure makes `turno browser doctor` exit with code 1.

## Why it happens

An identity's proxy signs in with a keychain: reference, and this machine has neither the macOS Keychain tool nor secret-tool (libsecret), so turno cannot read the password and the browser does not start.

## Fix

Install libsecret (secret-tool), or use a proxy without a password.

No single command fixes this one, so doctor names the manual step.

Install libsecret (secret-tool) on Linux, or use a proxy without a password.

Then run `turno browser doctor` again to see the row turn into `ok`.
