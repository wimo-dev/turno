This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  could not read <label>'s config <file>: <error>
     manual: fix the file by hand; doctor only reads it, to see which identities the agent has
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

doctor reads each agent's own config file (~/.claude.json, ~/.codex/config.toml, ~/.cursor/mcp.json, ~/.copilot/mcp-config.json, ~/.gemini/settings.json) to see which identities it has. This one exists and is not valid JSON or cannot be opened, so the agent likely cannot read it either. doctor never writes it.

## Fix

Fix the file by hand; doctor only reads it, to see which identities the agent has.

No single command fixes this one, so doctor names the manual step.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
