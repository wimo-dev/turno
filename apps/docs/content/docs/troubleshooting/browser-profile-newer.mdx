This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  the profile was last opened by version <last>, newer than <label> <version>: an older browser can refuse a profile whose data a newer one upgraded
     manual: update <label>, or open the profile with the browser that last used it
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

The profile's `Last Version` is newer than the identity's browser: it was opened by a newer browser, or by another one with --force. Chromium upgrades a profile's databases, and an older build can refuse them.

## Fix

Update &lt;label&gt;, or open the profile with the browser that last used it.

No single command fixes this one, so doctor names the manual step.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
