This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  x  the vault has <sites> credential<s> in the secret store, and this machine has none
     manual: install libsecret (secret-tool), then add them again with turno browser vault add
```

It is a failure; a failure makes `turno browser doctor` exit with code 1. Words in angle brackets stand for values from your machine.

## Why it happens

The identity's vault keeps each site's credentials in the secret store, and this machine has neither the macOS Keychain tool nor secret-tool (libsecret), so browser_login cannot sign in anywhere.

## Fix

Install libsecret (secret-tool), then add them again with turno browser vault add.

No single command fixes this one, so doctor names the manual step.

Install libsecret (secret-tool) on Linux, then add the credentials again with turno browser vault add. On Windows turno-browser has no secret store yet, so the vault does not work there.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
