This page is for when `turno browser doctor` reports the finding below: what it means and how to fix it.

## What you see

```text
  !  <label> no longer has <server>, which init registered in <file>
     fix: turno browser setup <agent> --identity <id>
```

It is a warning; warnings do not change the exit code. Words in angle brackets stand for values from your machine.

## Why it happens

init registered the identity's MCP server in this agent's config, and the config no longer has it: it was removed in the agent, or the file was replaced.

## Fix

Run:

```sh
turno browser setup <agent> --identity <id>
```

`turno browser doctor --fix` does not run it for you, because it needs a decision or an answer from you.

Then run `turno browser doctor` again to see the row turn into `ok`.

The check lives in [`packages/browser/src/doctor.ts`](https://github.com/wimo-dev/turno/blob/main/packages/browser/src/doctor.ts).
