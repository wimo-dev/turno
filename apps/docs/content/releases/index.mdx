turno and turno-browser are released on their own, each with its own version numbers. Each version of each has a page: what changed, how to use it and what to run when you upgrade. Each package's full changelog is on GitHub, and each GitHub release links back here. To follow one product only, see [turno releases](/releases/cli) or [turno-browser releases](/releases/browser).

To see the version you have, run `turno version`; `turno upgrade --check` only asks the registry whether there is a newer one.

## Versions

turno-cli and turno-browser each follow semantic versioning, with their own numbers, and every version either of them publishes has its page here. While a product is below 1.0, a minor version (0.6, 0.10) can change behavior, and its page says what changed under "Changed behavior". `turno-core` and `turno-fonts` follow their own numbers too; they have no pages, and the page of each release names the ones it published.
