Most of this release is [turno-browser 0.11.0](/releases/browser/0-11-0): features on by default, natural language actions whenever a model can answer, a live view with the agent's steps, the last click left to you, compact snapshots, and faster actions that check their element.

## Upgrade

<Upgrade>

**Update `turno-cli` and `turno-browser` together**, as with every release.

</Upgrade>

## More

- **New mcp.toml blocks**: turno prints the block of a new identity with `exclusive = false`, except in attach mode.
- **`turno help environment`** lists `TURNO_BROWSER_SNAPSHOT`.
- **`turno browser live`** without a running server no longer says the view is off when only no server runs.
