Most of this release is [turno-browser 0.8.0](/releases/browser/0-8-0), which keeps every password and one-time code away from the agent and lets the agent hand you the steps that are yours. In turno itself, mcpd sends the client's name with each call, so each agent session's cursor is named after its own agent. The hidden prompt of `turno browser replay` names the parameters it asked for to the server it starts in `TURNO_BROWSER_PROMPTED_PARAMS`, which `turno help environment` lists.
