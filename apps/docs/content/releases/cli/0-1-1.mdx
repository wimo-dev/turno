The first public release of turno: **[one MCP gateway](/docs/concepts/gateway)** for every agent session, **[profiles](/docs/concepts/profiles)** for Claude Code, Codex CLI, GitHub Copilot CLI and Cursor CLI, **[folder rules](/docs/concepts/folder-rules)** that pick the account, **[the Claude Code status line](/docs/concepts/profiles#the-status-line)** with usage per account, and **[the accounts bridge](/docs/concepts/profiles#service-accounts-and-the-accounts-bridge)**. 0.1.0 came out on November 16, 2026, and 0.1.1 the same day.

## Upgrade

0.1 is the first release. To move a 0.1 install to the newest version:

<Upgrade>

**With Homebrew on 0.1.0, use the Homebrew tab.** `turno upgrade` learned to recognize a Homebrew install in 0.1.1; before that it runs `npm install --global`.

</Upgrade>

## Gateway

- **mcpd**: tool lists from a cache, servers started on first use, shared between sessions where it is safe and stopped when idle.
- **Secrets**: in the macOS Keychain.
- **Your existing servers**: `turno mcp import`, `install`, `sync`, `config` and `doctor` move them behind the gateway.
- **More agents**: gateway entries for opencode, Gemini CLI, Goose, Crush, Droid and Kiro, with `turno mcp config --agent <name>`.

## Accounts

- **Profiles**: Claude Code, Codex CLI, GitHub Copilot CLI and Cursor CLI, each with its own sign-in folder and launcher. Claude Code profiles share conversations, skills and settings.
- **Folder rules**: `turno profile assign` and `turno auto [--agent]` open each folder with its account.
- **Accounts bridge**: a builtin MCP server that delegates a task to a service account another profile is signed into, with confirmation for writes and an audit log.

## CLI

- **Status line**: usage per account, with its font and terminal setup (`turno ui install`). The font comes from turno-fonts: MesloLGS Nerd Font 3.4.0 with checksums.
- **`turno status` and `turno doctor --fix`**: where you stand, and the fixes turno can make itself.
- **Scripts**: `--json` on reads, `--dry-run` and `turno undo` on writes, and shell completion.
- **Updates**: `turno upgrade`, and a daily update check that honors `DO_NOT_TRACK`.

## Browser

- **turno-browser**: an MCP server that drives your installed Google Chrome with a persistent profile per identity (`turno-browser-mcp --identity <name>`), headed by default, plus the `turno browser bench` checks.

## Fixes

0.1.1, the same day:

- **`turno upgrade`**: recognizes a Homebrew install and runs `brew update` and `brew upgrade turno` instead of `npm install --global`.
- **Repository**: moved to `github.com/wimo-dev/turno`, and turno-browser is listed in the MCP Registry as `io.github.wimo-dev/turno-browser`.
