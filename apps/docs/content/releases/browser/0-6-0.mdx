## Highlights

<Highlight area="Browser" title="Shell completion for turno-browser" href="/docs/browser/get-started#shell-completion-optional" more="Shell completion">

`turno-browser completion` prints a script for zsh, bash or fish. It completes commands, identity names, the agents `setup` knows, the actions of `do` and each command's flags. It only reads the identity folders: completing never starts Chrome or reads the secret store.

```sh
echo 'source <(turno-browser completion zsh)' \
  >> ~/.zshrc
echo 'eval "$(turno-browser completion bash)"' \
  >> ~/.bashrc
```

</Highlight>
