Released with [turno 0.2.0](/releases/cli/0-2-0), which gives the CLI a new look and makes the gateway do more with less.

## Browser

- **Engine ids**: `turno browser bench` names its engines `chrome-headed`, `chrome-headless`, `chrome-baseline` and `firefox`. `--engine` still accepts the old ids.
- **Asks first**: `turno browser bench` asks before it opens Chrome on third-party test pages. `--only-urls` replaces `--no-detectors`, which still works.
- **`turno-browser-mcp`**: refuses `--port` or `--host` together with `--identity`, which would serve a signed-in browser over HTTP. `--allow-http-identity` accepts it, and then it listens on 127.0.0.1 only.

## Changed behavior

What can break a script or a habit when you upgrade from 0.1:

- **`turno browser bench`**: reports the new engine ids in its table and `--json`, and without a terminal it needs `--yes` (`--json` alone no longer runs it).
